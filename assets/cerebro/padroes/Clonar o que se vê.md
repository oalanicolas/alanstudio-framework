# Clonar o que se vê

A lista de features visíveis não é o jogo. O que segura a experiência são as relações invisíveis.

- Onde: *Pontos cegos* do [[Estudo Hexa Drop]] (o anel incompleto, não “peça que cai”);
  [[Estudo Cai-Cai]] (a linha some só se fechar — um clone da queda perde a punição).
- Antídoto: todo estudo tem pontos cegos ou uma lista “o que precisa coexistir”.
  A tradução para o nosso jogo é uma tabela (copiar · adaptar · recusar), não um
  parágrafo de features.

- Instância proibida: lista de features visíveis entregue como desenho do jogo, sem o
  mecanismo que as liga.
- Fronteira: quando o pedido **é** paridade visível declarada (ícone, layout, teclas),
  copiar o que se vê é a tarefa. A armadilha é chamar isso de design.
