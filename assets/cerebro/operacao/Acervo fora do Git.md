# Acervo fora do Git

Vídeo, render, captura de QA e PSD não entram neste repositório. `_anexos/` leva
JSON, scripts e imagens leves que o estudo precisa. O resto: acervo externo, com
caminho, hash e instrução de recuperação na nota que usa o ficheiro.

Isto é o análogo operacional do laboratório (Drive). Troque o destino pelo vosso.
